# AI Screen Privacy Protection System

## 🚀 Features
- Manual Mode:
  - Dim, Blur, Vignette, Focus
- AI Mode:
  - Detects number of users
  - Warning → Dim → Lock system
  - Auto-lock when user absent

## 🧠 Tech Stack
- Electron.js
- Node.js
- React.js
- Python (MediaPipe, OpenCV)

## ⚙️ Setup Instructions

### 1. Install dependencies
npm install

### 2. Run Electron App
npm start

### 3. Run AI Backend
cd backend
pip install -r requirements.txt
python face_detection.py
